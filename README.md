# Data Science & Macroeconomics

A public resource hub for Carlos Mendez’s *Data Science and Macroeconomic Models: A Python Companion to Intermediate Macroeconomics*.

- Website: https://quarcs-lab.github.io/macro102-hub/
- Book: https://quarcs-lab.github.io/macro102-site/

Six static pages: Home, AI Podcasts, AI Tutors (forthcoming), Data Apps, Figure Apps, and a separate Japanese AI Podcasts page. The English podcast page links to the Japanese collection beside its episode directory button. The Japanese page lists published Japanese audio and marks chapters still in production. The Book navigation item opens the existing book. The homepage presents all 21 chapters as question-led cards with expandable mind maps, resource buttons, and inline podcast players; nine appendix cards sit in a disclosure below them. Its three pillars follow the preface: From data to facts, From facts to models, and AI-powered learning.

The hub catalogs 21 chapter data-app collections, 17 model-app collections, 21 English podcasts, and each publicly verified Japanese podcast episode. Audio remains hosted by the book website; timed transcripts and reading pages are local. Japanese episodes use the same generated player as the English collection, with Japanese timed read-along text and an English Japanese study-transcript link.

## Preview and build

```sh
python3 scripts/build_site.py
python3 scripts/check_site.py
python3 -m http.server 8765
```

No JavaScript dependencies or backend are needed. GitHub Actions validates and deploys the public runtime files to GitHub Pages on pushes to `main`.

## Refresh from the public book checkout

```sh
python3 scripts/refresh_resources.py --book ../macro102-site
python3 scripts/build_charts.py --book ../macro102-site
python3 scripts/build_site.py
python3 scripts/check_site.py --remote
```

Resource refresh uses macOS `sips` for compact chapter preview images and requires the installed `created-audio-player` skill (`--player-skill PATH` overrides its location). Chart generation needs Matplotlib. Ordinary builds use committed charts and player assets and require only Python’s standard library.

`data/resources.json` is the shared resource manifest. `scripts/build_site.py` owns the generated HTML pages; edit its content/templates, then rebuild. `assets/site.css` owns the shared visual design; `assets/home.css` follows the sister site's hero and curriculum layout. `assets/site.js` owns navigation, filtering, the accessible mind-map dialog, and the six-topic carousel. `data/curriculum.json` contains book-grounded questions and introductions, retained when resource metadata is refreshed. Full-resolution WebP maps use verified public repository URLs because the book's Pages build omits some original images. `data/chart-sources.json` records chart inputs, transformations and model parameters. The checked-in CSVs come from the public companion repository. Chart previews are original vector renderings of its data and models, not textbook scans.

The AI Podcasts page follows the sister site’s featured-episode hero, chapter directory, and two-column mind-map/player layout. `assets/podcasts.css` and `assets/podcasts.js` own that page’s presentation and featured playback. `listening_player()` in the site generator adapts each widget to show its controls immediately, moves artwork into the episode context, and retains hidden disclosure hooks for the shared runtime. Listening topics come directly from the timed transcript sections; the existing chapter questions and introductions supply episode context.

Data Apps and Figure Apps use featured chapter mind-map heroes and two-column chapter grids, styled by `assets/apps.css`. Cards reuse the curriculum questions and introductions, link to full-resolution mind maps, and open each chapter’s existing app collection. Only chapters with available collections appear: 21 for data and 17 for figures. Shared search includes chapter titles, questions, and app topics; topic filters remain available. The grid stacks on phones.

The navy/coral audio player is generated by the user’s standard `created-audio-player` skill. Do not hand-edit generator-owned files in `audio-player/`; edit `player-config.json` or the skill and regenerate. Transcripts preserve the source timing and complete text.

## Home page in English, Spanish and Japanese

The home page is available in English, Spanish and Japanese: `index.html`, `es/index.html` and `ja/index.html` come from one template in `scripts/build_site.py`, with their strings in `data/i18n/en.json`, `es.json` and `ja.json` (the chapter questions and introductions of the English page stay in `data/curriculum.json`). `assets/i18n.js` sends Spanish (`es*`) and Japanese (`ja*`) browsers from the English home page to `es/` or `ja/`, remembers the language picked in the switcher under the hero (shared with the book's home pages, which use the same key), and translates the English podcast player's runtime labels. The standalone `podcasts-ja.html` page presents the Japanese podcast collection. `scripts/build_charts.py` draws each carousel chart in all three languages (`name.svg`, `name-es.svg`, `name-ja.svg`).

`scripts/check_site.py` fails when `en.json` or `curriculum.json` changed after the translations were made. Update `es.json` and `ja.json`, then run `python3 scripts/check_site.py --stamp-i18n`.
