# Data Science & Macroeconomics

A public resource hub for Carlos Mendez’s *Data Science and Macroeconomic Models: A Python Companion to Intermediate Macroeconomics*.

- Website: https://quarcs-lab.github.io/macro102-hub/
- Book: https://quarcs-lab.github.io/macro102-site/

Five static pages: Home, AI Podcasts, AI Tutors (forthcoming), Data Apps, and Figure Apps. The Book navigation item opens the existing book. The hub catalogs 21 chapter data-app collections, 17 model-app collections, 21 English podcasts, and 30 chapters/appendices. Audio remains hosted by the book website; timed transcripts and reading pages are local.

## Preview and build

```sh
python3 scripts/build_site.py
python3 scripts/check_site.py
python3 -m http.server 8765
```

No JavaScript dependencies or backend are needed. GitHub Actions validates and deploys the public runtime files to GitHub Pages on pushes to `main`.

## Refresh from the public book checkout

```sh
python3 scripts/refresh_resources.py --book ../macro102-site
python3 scripts/build_charts.py --book ../macro102-site
python3 scripts/build_site.py
python3 scripts/check_site.py --remote
```

Resource refresh uses macOS `sips` for compact chapter preview images and requires the installed `created-audio-player` skill (`--player-skill PATH` overrides its location). Chart generation needs Matplotlib. Ordinary builds use committed charts and player assets and require only Python’s standard library.

`data/resources.json` is the shared resource manifest. `scripts/build_site.py` owns all five generated HTML pages; edit its content/templates, then rebuild. `assets/site.css` and `assets/site.js` own the design and progressive enhancements. `data/chart-sources.json` records chart inputs, transformations and model parameters. The checked-in CSVs come from the public companion repository. Chart previews are original vector renderings of its data and models, not textbook scans.

The navy/coral audio player is generated by the user’s standard `created-audio-player` skill. Do not hand-edit generator-owned files in `audio-player/`; edit `player-config.json` or the skill and regenerate. Transcripts preserve the source timing and complete text.
